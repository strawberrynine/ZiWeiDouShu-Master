# 格局识别与破格

## 规则

- **[SOURCE]** 原典格局论见印刷 pp.152–155，富贵贫贱论见 pp.156–157。
- **[FRAMEWORK]** 格局是多星、多宫和亮度的条件集合，不是单星标签。
- 只有“必须条件”齐全才写“检测到某格”；缺条件写“类似某格的局部倾向”。
- 同时记录加分项、破格项和证据页码；破格不抹掉原格，而是解释为什么结论降级。

## 格局记录格式

```yaml
name: 杀破狼
level: neutral | good | caution
required:
  - 七杀在命宫三方四正
  - 破军在命宫三方四正
  - 贪狼在命宫三方四正
bonus: []
breaking: []
palaces: [命宫, 财帛, 官禄, 迁移]
source: 《紫微斗数》格局论, pp.152-155
confidence: medium
```

## 适用的结构化格局

| 格局/组合 | 必须条件 | 可解释主题 | 破格提示 |
|---|---|---|---|
| 杀破狼 | 七杀、破军、贪狼齐会命宫三方四正 | 变化、开创、竞争，宜在变化中建立专长 | 三方煞重、空劫或化忌使代价增加 |
| 紫府同宫 | 紫微、天府同宫；若论命格还需坐命 | 平台、统筹、资源承载 | 空劫、双煞或不坐命降级 |
| 府相朝垣 | 天府、天相分守命宫三方 | 组织、行政、资源与协调 | 命宫煞重或三方煞过多 |
| 阳梁昌禄 | 太阳、天梁、文昌、禄存会命三方 | 专业声望、表达、制度内发展 | 太阳落弱、煞重 |
| 火贪/铃贪 | 贪狼与火星/铃星有效同会且贪狼在命三方 | 快速机会、强刺激和资源整合 | 羊陀、空劫或化忌；不作财富保证 |
| 机月同梁 | 四星齐会命三方 | 规划、服务、教研、制度与长期积累 | 缺星时仅部分会照 |
| 昌曲/辅弼/魁钺同会 | 对应成对吉曜同会命三方 | 文书表达、团队、贵人 | 单星或目标宫承载不足 |

## 现代化输出

用“这组条件支持……，但因……破格，所以表现为……”；不要复述古籍中的死亡、牢狱、灾厄等断语。若用户明确要求传统原文，可先给历史语境，再给现代非决定性解释。
