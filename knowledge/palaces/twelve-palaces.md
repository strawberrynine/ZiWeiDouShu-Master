# 十二宫知识与联参图

## 宫位定义

| 宫位 | 首要问题 | 对宫 | 常用三方四正 |
|---|---|---|---|
| 命宫 | 核心人格、人生主轴 | 迁移 | 财帛、官禄、迁移 |
| 兄弟/仆役 | 同辈、朋友、合作网络 | 交友/兄弟 | 视排盘宫序联参 |
| 夫妻 | 配偶类型、关系互动、婚姻形式 | 官禄 | 福德、迁移、官禄（专题加命宫） |

| 财帛 | 收入、赚钱方式、现金流 | 福德 | 命、官禄、迁移 |

| 官禄 | 职业、职位、社会角色 | 夫妻 | 命、财帛、迁移 |

| 父母 | 长辈、早年资源、制度支持 | 疾厄 | 命、福德、田宅 |

## [FRAMEWORK] 目标宫分析模板

1. 确定目标宫 branch/name、主星、亮度、同宫辅煞和四化。
2. 读取对宫：它是目标宫的外部投影、现实场景或压力来源，不是简单“相反”。
3. 读取三方四正：看功能支持链是否完整；若三方主星互相冲突，保留冲突。
4. 需要时读夹宫、身宫和命宫，判断资源是否会落到当事人的行动上。
5. 叠加本命四化，再叠加大限/流年触发，最后输出证据和反证。

## 主题联参

- 感情/婚姻：夫妻 + 命 + 福德 + 迁移 + 官禄 + 三方四正 + 四化 + 限运。
- 事业：命 + 官禄 + 财帛 + 迁移 + 福德。
- 财富：财帛 + 命 + 官禄 + 福德 + 田宅。
- 城市/迁移：迁移 + 命 + 官禄 + 财帛 + 当前大限。
- 健康：疾厄 + 命 + 福德 + 限运；只能作生活节律提示。

## 不能单独定论的资料

单颗杂曜、单一桃花星、宫名吉凶、古代格局名、某一流年煞名，都只能作辅助证据。没有出生资料或完整盘面时，明确写“信息不足”。
