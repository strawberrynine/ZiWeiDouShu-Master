# 时间层：本命、大限、小限、流年

## 层级

| 层 | 回答的问题 | 不能做什么 |
|---|---|---|
| 本命 | 长期先天结构 | 不能推出具体年份 |
| 身宫 | 实际着力点和后天表现 | 不能取代命宫 |
| 大限 | 十年主背景、机会、压力、重点迁移 | 不能写成十年必然事件 |
| 流年/太岁 | 某年触发哪些已有主题 | 不能脱离本命和大限独断 |
| 小限/月日时 | 更短的应期提示 | 证据弱时只作观察窗口 |

## [SOURCE] 叠加原则

原典大小限流年章节见印刷 pp.188–193，流年星煞见 pp.182–185。大限是背景，流年/小限是触发；“大限吉而流年不利”应解释为阶段底盘仍在、当年有局部阻力，“大限不利而流年吉”可能是短期机会，未必改变长期主题。

## 时间窗口算法（[FRAMEWORK]）

1. 从用户问题确定主题宫。
2. 找出本命中已存在的结构和未解决的矛盾。
3. 标记大限是否把主题宫、其三方、对宫或相关四化带入当前阶段。
4. 仅在本命和大限已有主题时，使用流年/小限的桃花、禄权科忌、岁煞作触发器。
5. 输出“窗口 + 可能事件类型 + 证据 + 反证”，而不是单一年份断言。

## 事件类型标签

`relationship_start`、`relationship_define`、`relationship_adjust`、`career_change`、`income_growth`、`asset_building`、`expense_pressure`、`relocation`、`study_or_credential`、`health_routine_reflection`。

每个窗口必须说明是机会、升级、调整、压力或支出，避免把所有吉星都叫“发财”。
