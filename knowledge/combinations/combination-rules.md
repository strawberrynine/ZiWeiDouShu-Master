# 星曜组合与会照规则

> 组合名只有在条件完整、宫位关系正确时才可使用。没有检测到完整条件时，用“组合倾向”而不是格局名。

## 组合读取层级

1. **同宫**：两个或多个星在同一宫，最直接但也最容易被煞曜改变。
2. **三方四正**：目标宫、三合宫和对宫共同构成一组功能场；看支持链是否闭合。
3. **夹宫**：前后宫夹入资源或压力；只有在主星和会照已成立时作加减分。
4. **四化**：确定动力方向，记录化星、来源天干和落宫，不把“化”当成静态吉凶。

## 常见可执行组合

| 组合 | 条件 | 现代化解释 | 破格/限制 |
|---|---|---|---|
| 杀破狼 | 七杀、破军、贪狼在命宫三方四正 | 人生变化、竞争、开创和转型较强 | 煞重/空劫/化忌时波动与代价增 |
| 紫府 | 紫微与天府同宫或会照 | 统筹、资源、平台与稳定度 | 不在命宫只能作辅助；空劫会削弱稳定 |
| 府相朝垣 | 天府、天相分布于命宫三方四正 | 组织管理、资源与协调能力 | 需检查煞曜和命宫承载力 |
| 机月同梁 | 天机、太阴、天同、天梁会于命三方四正 | 规划、服务、制度和专业积累 | 星缺一两颗时只能称“部分会照” |
| 昌曲同会 | 文昌、文曲同入或同会目标三方 | 表达、学习、文书、审美 | 化忌或煞重时注意误会、文书风险 |
| 辅弼/魁钺同会 | 左右或魁钺成对会照 | 团队支持、贵人和资源入口 | 单星不等于成格；仍需主星可承接 |
| 火贪/铃贪 | 贪狼与火星/铃星同宫或有效会照 | 突发机会、强刺激、快速变现的倾向 | 不是保证横财；羊陀空劫或化忌时风险大 |
| 日月同梁等 | 太阳、太阴、天梁等形成会照 | 外向担当与内在照料的张力 | 旺弱、性别和四化必须核对 |

## `[DERIVED]` 组合判定伪代码

```text
for target in requested_palaces:
  collect(target, opposite, trines, jia, major_stars, transformations)
  identify only combinations whose full conditions are present
  add supporting stars and malefics with location and brightness
  write both support and counterevidence
  lower confidence when the combination depends on OCR, a single minor star, or a disputed school rule
```

## 禁止的跳步

- “贪狼 = 一定花心/出轨”。应写吸引力、欲望、社交和边界议题。
- “七杀/破军 = 一定离婚或灾难”。应写空间需求、变化和压力管理。
- “火贪 = 一定暴富”。应写机会速度与风险并存，并回到财帛/官禄/限运。
- 组合格局名不能替代目标宫、命身宫和时间层的证据。
