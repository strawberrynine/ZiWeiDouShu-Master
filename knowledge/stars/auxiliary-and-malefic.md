# 辅星、吉曜与煞曜

## 分组

| 组别 | 星曜 | 结构化作用 |
|---|---|---|
| 辅弼 | 左辅、右弼 | 他人协助、团队、伴侣互助；单星不等于完整支持 |
| 魁钺 | 天魁、天钺 | 关键贵人、机会入口、被提携；需有可承接的本宫结构 |
| 昌曲 | 文昌、文曲 | 表达、文书、学习、审美；化忌/煞重时注意误会和契约 |
| 禄类 | 禄存、化禄 | 资源、收入、关系中的照顾与实际帮助；也可能带来占有和守成 |
| 动星 | 天马 | 外出、跨地、奔波、服务；与天梁/关系宫联动时注意分隔 |
| 桃花/喜庆 | 红鸾、天喜、咸池、天姚 | 吸引力、社交、喜庆或关系触发；不等于出轨 |
| 四煞 | 擎羊、陀罗、火星、铃星 | 冲突、急躁、拖延、突发；看数量、亮度、会照和是否有吉曜缓冲 |
| 空耗 | 地空、地劫、天空、旬空、截空 | 理想与现实落差、资源难聚、计划改变；不直接等于失败 |
| 孤寡 | 孤辰、寡宿 | 独处、界限、聚少离多或不易表达；必须结合主星和现实选择 |

## 使用约束

- `[DERIVED]` 同一主题若出现至少两颗独立吉曜，可提升“支持/资源”证据；若煞曜来自三方而非本宫，标为外部压力，不直接改写本宫主星。
- `[DERIVED]` 同一宫吉煞并见时，输出“有机会但需要条件”，说明吉曜缓冲和煞曜触发各自作用。
- 禁止把“桃花星”直接写成“有外遇”，把“孤寡星”直接写成“必不婚”，或把四煞直接写成灾难。
