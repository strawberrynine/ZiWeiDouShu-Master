# Topic Router

先从用户问题抽取主题，再读取对应框架。多个主题时按用户最先、最明确的问题排序。

| 触发词/意图 | 核心宫位 | 辅助宫位 | 框架 |
|---|---|---|---|
| 另一半、配偶画像、对象是什么样 | 夫妻 | 命、福德、官禄、迁移 | `spouse-analysis.md` |
| 恋爱、桃花、婚姻稳定、正缘、分手 | 夫妻 | 命、福德、迁移、官禄、限运 | `relationship-analysis.md` |
| 职业、工作、升职、创业、行业 | 官禄 | 命、财帛、迁移、福德 | `career-analysis.md` |
| 发财、财运、收入、投资、资产 | 财帛 | 命、官禄、福德、田宅、迁移 | `wealth-analysis.md` |
| 城市、异地、出国、搬家、发展地 | 迁移 | 命、官禄、财帛、大限 | `migration-analysis.md` |
| 什么时候、哪几年、未来、流年、大限 | 主题宫 | 命、福德、相关限运 | `timing-analysis.md` |
| 健康、压力、作息 | 疾厄 | 命、福德、限运 | `full-chart-analysis.md`（健康边界） |
| 没有明确主题或首次拿盘 | 命/身 | 官禄、财帛、夫妻、福德、迁移 | `full-chart-analysis.md` |

路由只是入口，不是机械清单；根据问题缩小分析范围。
