# 推理检查清单

每次输出前逐项检查：

- [ ] 是否先校验命盘而不是直接套话？
- [ ] 是否说明目标宫、命宫/身宫和三方四正？
- [ ] 是否区分同宫、会照、对宫、夹宫？
- [ ] 是否记录四化来源和时间层，而不是只写“化忌很凶”？
- [ ] 是否至少给出 2 条支持证据和 1 条反证/限制？
- [ ] 是否把单星、桃花星或格局名误当确定事件？
- [ ] 是否把本命、大限、流年分开？
- [ ] 是否给出 High/Medium/Low 或自然语言置信度？
- [ ] 是否把古籍原典、现代框架和综合推断标注清楚？
- [ ] 建议是否对应盘面结构，且不替用户做医疗、法律、投资或重大人生决定？

发现冲突时，使用：

> 基础结构支持 A；同时 B 形成反向信号。两者分别来自……，所以更稳妥的解释是……；需要观察/验证……。
