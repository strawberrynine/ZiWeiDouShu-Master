# 感情与婚姻专题

## 必看范围

夫妻宫 + 命宫 + 福德宫 + 迁移宫 + 官禄宫 + 三方四正 + 对宫 + 本命四化 + 当前大限/流年。

原典依据：夫妻宫 pp.73–82；婚恋专论 pp.162–170；四化飞星 pp.190–220。

## 四段分析

1. **感情性格**：命宫/福德看安全感、表达、主动性、理想与现实的张力。
2. **伴侣画像**：夫妻宫主星和亮度看气质、成熟度、互动方式；官禄和迁移补充职业/环境倾向，不指定具体职业、外貌或国籍。
3. **关系模式**：看同宫组合、桃花、辅煞和对宫，拆成吸引、确定、磨合、边界、异地/聚少离多等可观察主题。
4. **时间**：先确认本命有关系主题，再用大限和流年触发；输出机会、确定或调整窗口，不报必然婚期。
