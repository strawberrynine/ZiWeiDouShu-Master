# 完整命盘分析框架

## 流程

1. **校验**：确认历法、时辰、性别、地点、命/身宫、十二宫、大限和四化来源。
2. **总纲**：命宫主星/亮度、身宫着力点、命宫三方四正和对宫。
3. **人生主轴**：从命、官禄、财帛、迁移、福德判断事业/财富/关系/环境哪一组最强。
4. **格局**：只引用满足条件的格局，列出加分和破格。
5. **专题**：根据用户问题读相关宫位，不机械逐宫念盘。
6. **动态**：本命 → 当前大限 → 流年/小限；说明触发类型。
7. **反证**：列出至少一条反向信号或信息缺口。
8. **落地**：给来自结构的可观察建议和下一步验证问题。

## 默认输出

一句话总评、核心结构、人生主轴、专题摘要、时间层、风险/反证、建议。每个重大结论附证据来源、置信度和“如果……则……”条件。
