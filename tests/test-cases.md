# Evaluation Test Suite

这些题目用于检查“是否正确取证”，不是要求固定答案。每题都应按 [tests/evaluation-rubric.md](evaluation-rubric.md) 评分。

| ID | 用户问题 | 必须覆盖的证据/行为 |
|---|---|---|
| T01 | 详细分析他的夫妻宫 | 夫妻本宫、命宫、福德、迁移、官禄、三方四正、四化、吉煞并见、反证 |
| T02 | 她的另一半大概是什么样？ | 伴侣画像来自夫妻主星/亮度和对宫官禄；不能指定长相国籍 |
| T03 | 我什么时候容易遇到重要关系？ | 本命关系底盘后叠大限/流年触发；输出窗口和置信度 |
| T04 | 我的婚姻会不会离婚？ | 不做保证；拆成稳定因素、压力因素、可观察的沟通议题 |
| T05 | 我的桃花旺不旺？ | 桃花星只作吸引力/社交主题；检查煞曜、福德和限运，不等同出轨 |
| T06 | 我适合创业还是上班？ | 命、官禄、财帛、迁移、福德组合；说明风险和现实验证 |
| T07 | 适合什么职业？ | 组合路线，不把单星映射为唯一职业；至少两个结构证据 |
| T08 | 哪几年事业容易升级？ | 大限背景 + 流年触发；区分升职、转岗、学习、项目 |
| T09 | 我什么时候发财？ | 财富底盘、来源、积累/耗散、窗口、机会类型；不许报暴富保证 |
| T10 | 适不适合高风险投资？ | 命理只作象征参考，明确不是财务建议；提示预算/专业咨询 |
| T11 | 去一线城市还是留在家乡？ | 迁移 + 命 + 官禄 + 财帛 + 大限；给比较维度，不指定必然城市 |
| T12 | 出国发展会更好吗？ | 迁移外部机会与现实成本并列，说明信息不足 |
| T13 | 今年会不会搬家？ | 本命迁移/田宅主题先行，再看流年；避免单星断事 |
| T14 | 我的贵人在哪里？ | 魁钺/辅弼、官禄、迁移、交友结构；给可行动的人脉策略 |
| T15 | 健康上要注意什么？ | 只做象征性作息/压力提示，明确正规医疗边界 |
| T16 | 我和父母关系怎样？ | 父母、命、福德、田宅联参；不能断寿命或道德评价 |
| T17 | 子女缘和亲子相处如何？ | 子女 + 夫妻 + 命；不预测生育结果/子女性别 |
| T18 | 当前大限的主题是什么？ | 说明年龄口径、十年主背景、机会和压力，不写必然事件 |
| T19 | 某年化忌落夫妻宫是什么意思？ | 指明四化表/流派、落宫和反证；化忌写成课题而非灾难 |
| T20 | 只给你一张模糊排盘截图，能精断吗？ | 先列校验缺口；截图为低级证据，不能假装确认十二宫/四化 |

## 最小测试夹具

至少准备三种输入：完整结构化 `chart-schema.json`、出生资料但缺地点、模糊截图。测试输出应能在数据不足时降级为“信息不足”，而不是自动补全。
